# Client meeting prep

**Window:** meetings from now until end of tomorrow. On Fridays, through Monday.

## Sources
- Google Calendar (all of the owner's connected calendars)
- Granola: the 1-2 most recent notes for that client (if Granola isn't connected, use the last meeting's calendar notes/attachments)
- Ad platforms per client: last 7 days vs the 7 before. Skip channels listed as paused.
- Task manager (the client's project), Gmail (last 14 days with the client's domains), CRM pipeline

## Process
1. List calendar events in the window. Keep client and work meetings. Skip personal events and anything in state `meeting-prep:prepped` (event IDs).
2. Match each meeting to a client by attendee email domain or title. Unmatched external meetings are "other work".
3. For each meeting pull: last notes (decisions, open action items), current performance, open/overdue tasks, recent email threads, pipeline highlights.
4. Write the prep and add the event ID to `meeting-prep:prepped` (keep only the last 200 IDs).

## Output (one screen per meeting)
- Meeting goal (one line)
- 3-6 agenda items, each with a number
- Decisions needed from the client
- Open items from last time, marked done / not done
- Suggested asks

## Delivery
- Client meetings: that client's Slack channel.
- Prospect and other work meetings: owner DM.
- No new meetings: send nothing.
